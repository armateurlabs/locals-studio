Kapitsa 0.2.39: fast local Qwen on Apple silicon.

  kapitsa serve                 start the best model for this Mac (downloads it the first time)
  kapitsa serve --model 27b     start a given model

Then open http://127.0.0.1:8000 to chat, or point any OpenAI- or Anthropic-compatible app at
http://127.0.0.1:8000/v1. Or start a coding agent on it in one command:

  kapitsa claude                Claude Code
  kapitsa codex                 Codex
  kapitsa opencode              opencode
  kapitsa pi                    Pi
  kapitsa hermes                Hermes (Nous Research)
  kapitsa aider                 aider
  kapitsa goose                 Goose (Block)
  kapitsa copilot               GitHub Copilot CLI

Commands:
  serve        start the server: chat page at /, OpenAI and Anthropic APIs at /v1 (kapitsa serve --help)
  claude, codex, opencode, pi, hermes, aider, goose, copilot [--model M] [--port P] [--ctx N] [--api-key K] [agent args]
               start that coding agent on Kapitsa: on the server already running on the port, else on one
               started for it (with a context sized for agents; kapitsa claude --help)
  pull MODEL   download a model without starting it (kapitsa pull --help)
  list         downloaded models, their size and what they include
  rm MODEL     delete a downloaded model
  import FILE  convert a GGUF (LM Studio, Ollama, llama.cpp) into a model (kapitsa import --help)
  doctor       this Mac's GPU and memory, and which models fit it (kapitsa doctor --help)
  cluster      the Macs on this network that run Kapitsa: model, speed, link (kapitsa cluster --help)
  bench        benchmark Kapitsa (and other engines: bench compare) on this Mac (kapitsa bench --help)
  update       update Kapitsa to its latest release; it also updates itself (kapitsa update --help)

Models are stored in ~/.cache/kapitsa/models (KAPITSA_HOME moves them). HF_TOKEN is used when set.
